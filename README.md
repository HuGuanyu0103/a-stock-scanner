# A 股短线选股系统「观澜」— 完整技术文档

> 适用周期：超短线（2-4 天持股）  
> 当前版本：v4.5  
> 文档生成日期：2026-07-13  
> 代码总量：~12,800 行（35 个文件）

---

## 一、产品定位

面向 A 股个人投资者的**实时盘中选股 + AI 决策辅助工具**。核心思路是「**板块定方向 → 资金选个股 → 多系统交叉验证 → AI 诊断决策**」。不做自动交易，专注信号发现与策略建议。

**核心能力**：
- 盘中实时监控板块资金流向（概念 + 行业），每 3 秒刷新
- 从热板块成分股中多因子评分选出候选池（A 追涨 + B 低吸各 25 只）
- 技术面、情绪面、消息面三系统独立运行、交叉验证
- **AI Agent「观澜」**：个股诊断卡片、板块分析卡片、选股推荐、持股决策、Multi-Agent 辩论
- **SSE 流式输出**：LLM 回复首字延迟 < 2 秒，渐进式渲染
- **持仓陪跑**：输入持仓信息，AI 分析每只股票的操作策略
- **输出质量自检**：LLM 输出前逐条验证，无数据不输出
- 盘前简报自动推送微信（外盘映射 + 竞价异动 + 今日策略）

## 三、AI Agent「观澜」— 核心决策引擎

### 3.1 架构

```
用户输入 → _classify_question() → 7 种问题类型
  │
  ├─ stock_analysis    个股诊断（最核心功能）
  ├─ sector_analysis   板块分析
  ├─ market_analysis   大盘研判
  ├─ external_info     外围信息（外盘/美股/港股）
  ├─ holding_decision  持股交易决策
  ├─ stock_pick        选股推荐
  └─ general           通用咨询

每种类型 → 自适应 System Prompt → 上下文注入 → DeepSeek LLM → SSE 流式输出
```

### 3.2 个股诊断

后端链路：
```
用户输入 "600519"
  → screener.quick_scan()   → K线(120日) + 技术/情绪信号 + 19因子
  → analyzer.analyze_stock()→ 深度分析（复用K线，避免重复API）
  → /api/stock/diagnose     → 结构化 JSON（20+字段）
  → /api/agent/chat/stream  → LLM 流式诊断文本
```

前端渲染 — 诊断卡片：
- **Header**：股票名/代码/现价/涨跌幅
- **K线折叠面板**：近18日K线 + `← 底部区域 / 放量启动 / 天量 / 洗盘 / 反包 / 加速` 事件自动标注
- **四宫格**：量比 / 换手率 / 振幅 / 日内位置
- **信号标签**：Lv1-5 星级 + 颜色区分
- **评分条**：综合评分 + 日评分排名 渐变进度条
- **LLM 分析段**：K线量价分析 → 量价数据 → 技术研判 → 资金面 → 综合评分
- **操作建议**：彩色芯片（入场区间/目标/止损/仓位/周期/风险等级）
- **一句话总结**

### 3.3 板块诊断

- `/api/sector/diagnose?name=板块名`：返回排名、资金流时序、成分股
- 前端橙色卡片：板块概况 → 资金流向 → 持续性判断 → 操作策略
- 自动检测板块关键词，使用卡片渲染

### 3.4 输出质量自检

LLM 输出前执行 6 条自检，不通过则重新组织：
1. 每句结论是否有数据支撑？无数据→删除
2. 是否用了模糊词？→改为明确判断
3. 关键价格/点位是否有具体数字？
4. 操作建议 6 行格式是否完整？
5. 泛泛而谈是否超过 2 句？
6. 是否有 emoji？

### 3.5 SSE 流式输出

替换传统阻塞式请求，首字延迟 < 2 秒（原 8-10 秒）：
```
POST /api/agent/chat/stream
  → Response: text/event-stream
  → Phase 1: {type:"meta", kline, _ts, _ctx}     ← 立即渲染卡片壳子
  → Phase 2: {type:"chunk", data:"..."} x N       ← 渐进填充分析文本
  → Phase 3: {type:"done"}                         ← 完成
```
前端通过 `fetch + ReadableStream` 解析，逐 chunk 渲染。

## 四、核心选股策略

### 4.1 A/B 双轨选股

**A 池 — 当日热力追涨**
```
热板块排名（概念 Top5 + 行业 Top5，双维度：资金流 + 价格动量）
  → 合并去重 (10-15 个板块)
  → 成分股下钻（每板块取主力净流入 Top 50）
  → 去重 + 过滤 + 9 因子评分
  → 板块集中度管控（每板块 ≤8 只）
  → Top 25 输出
```

**B 池 — 周期回调低吸**
```
SectorReviewer 回溯近 3 日
  → 筛选：累计流入≥3亿 + 累计涨幅达标(按规模分级) + 曾入 Top 50 + 当日回调
  → 成分股下钻 (Top 50)
  → B 池专属评分（取消低开惩罚、独立偏离逻辑）
  → Top 25 输出
```

**动态池分配**：由情绪面轮动速度决定 A/B 比例

| 轮动速度 | A 池 | B 池 | 策略倾向 |
|:--------:|:----:|:----:|----------|
| < 0.3（慢） | 35 | 15 | 追涨为主 |
| 0.3–0.6（中） | 25 | 25 | 攻守平衡 |
| 0.6–0.85（快） | 15 | 35 | 多低吸 |
| > 0.85（极快） | 5 | 45 | 只防守 |

### 4.2 两层评分体系

| 层级 | 来源 | 计算时机 | 权重 | 含义 |
|------|------|:------:|:----:|------|
| 盘中评分 | stock_selector | 每 60 秒 | 75% | 资金流 + 量价因子，「今天谁在涨」 |
| 日评分 | daily_scorer | 盘前一次性 | 25% | 技术面 + 情绪信号，「谁形态好」 |

日评分在全量样本中做百分位归一化后按 25% 权重并入。

### 4.3 盘中 9 因子评分模型

| 因子 | 权重 | 归一化 | 说明 |
|------|:----:|--------|------|
| volume_ratio 量比 | 20% | Min-Max | 超短线量是王 |
| price_deviation 智能偏离 | 16% | 资金-价格矩阵 | 核心创新 |
| net_main_ratio 主力净占比 | 16% | Min-Max + 置信度降权 | 资金确认信号 |
| intraday_position 日内位 | 12% | Min-Max + 惩罚 | 高位/低位惩罚 |
| open_return 开盘涨幅 | 10% | Min-Max + 方向惩罚 | 低开惩罚 |
| turnover_rate 换手率 | 8% | Min-Max | 流动性 |
| amp_ratio 振幅 | 6% | Min-Max | 盈利空间 |
| short_momentum 短动量 | 6% | Min-Max | 近 5 日趋势 |
| breakout_dist 突破距离 | 4% | Min-Max | 距 20 日高点 |

### 4.4 智能偏离评分（核心创新）

```
                    跑输板块              跑赢板块
                  (deviation<0)         (deviation>0)
  ┌─────────────┬─────────────────┬─────────────────┐
  │ 主力强流入   │  补涨潜力  1.0  │  强势龙头  1.0  │
  │ net_ratio>5 │  (资金抄底)     │  (资金追涨)     │
  ├─────────────┼─────────────────┼─────────────────┤
  │ 主力温和流入 │   滞涨   0.40   │  温和偏强 0.75  │
  ├─────────────┼─────────────────┼─────────────────┤
  │ 主力持平     │    0.25        │  一般    0.55   │
  ├─────────────┼─────────────────┼─────────────────┤
  │ 主力流出     │  真弱势   0.0   │ 拉高出货  0.1   │
  └─────────────┴─────────────────┴─────────────────┘
```

### 4.5 信号推断体系（13 种）

**A 池信号（10 种）**：放量上攻、放量突破、补涨潜力、资金驱动、量价齐升、弱势回避、滞涨关注、温和吸筹、高位风险、盘中观察

**B 池专属（3 种）**：主线分歧低吸、板块洗盘承接、缩量止跌企稳

每种信号均附带持股天数 + 固定止盈止损 + ATR 动态止盈止损建议。

### 4.6 三级系统性风控熔断

| 级别 | 触发条件 | 动作 |
|:----:|------|------|
| **大盘** | 上涨板块占比 < 8% | A 池归零，全部转 B 池防守 |
| **板块** | 主力净流出 > 20 亿 + 跌幅 > 3% | 该板块成分股得分 ×0.5 |
| **个股** | 开盘后跌幅 > 4% + 现跌幅 > 5% | 直接剔除候选池 |

### 4.7 过滤规则链

```
全量成分股 (15板块 × 50只/板块 ≈ 750)
  → 智能去重（跨板块时保留资金流入最强的归属）
  → 板块排除（688科创板、8/9北交所）
  → 流动性过滤（流通市值≥30亿 A / ≥20亿 B、换手≥0.5%）
  → 涨停板过滤（反推涨停价，已涨停剔除）
  → 急跌熔断过滤（开盘后持续下挫剔除）
  → 诱多出货预警（高位+流出+高开低走剔除）
  → 极端背离剔除（价格大涨+主力明显流出）
  → 板块集中度管控（每板块≤8只）
  → Top 25 + 25 输出
```

## 五、数据基础设施

### 5.1 数据源

| 数据 | 接口 | 频率 | 降级方案 |
|------|------|:--:|------|
| 概念板块资金流 | push2 `m:90+t:3` | 3 秒 | 退避重试(4次) → 熔断 → DB缓存 |
| 行业板块资金流 | push2 `m:90+t:2` | 3 秒 | 同上 |
| 北向资金 | push2 `/api/qt/kamt/get` | 6 秒 | 退避重试(3次) → 熔断 |
| 板块成分股 | push2 `b:板块代码` | 60 秒 | 退避重试(3次) → 跳过 |
| 全 A 股资金流排名 | push2 `m:0+t:6,...` | 按需 | 退避重试(3次) → AKShare |
| 个股实时行情 | adata → **腾讯 qt.gtimg.cn** | 按需 | 腾讯 API 零成本降级 |
| 交易日历 | akshare | 启动时 | - |
| 涨停板数据 | akshare `stock_zt_pool_em()` | 5 分钟 | - |
| 新闻标题 | 财联社 cls.cn | 60 秒 | - |
| DeepSeek LLM | deepseek-chat | 按需 | 7 种问题类型 |

### 5.2 多级降级 + 熔断器

```
push2 调用
  → 退避重试 (1.5s → 3s → 6s → 12s + 随机抖动)
  → 连续失败 3 次 → 熔断器开启（60 秒冷却）
  → 新交易日自动重置所有熔断器
  → 腾讯 qt.gtimg.cn 兜底个股行情
  → DB 持久化缓存兜底板块数据
  → /api/status 暴露熔断器状态
```

### 5.3 板块白名单体系

25 个自选板块，通过三种方式映射到东方财富 API：

- **精确匹配**（13 个）：「光通信模块」「数据中心」「军工」等
- **名称映射**（9 个）：「人形机器人」→「机器人执行器」、「AI 芯片」→「华为昇腾」等
- **加权合成**（11 个）：「半导体」= 模拟芯片设计×0.6 + 华为昇腾×0.4 等

### 5.4 持久化

- **SQLite** (`collector.db`)：板块快照分钟级时间序列，供回放和回溯
- **JSON 缓存** (`data/daily_scores_YYYYMMDD.json`)：日评分全市场扫描结果
- **JSON 缓存** (`data/last_picks_result.json`)：最后一份真实选股结果，灾备
- **JSON 信号** (`data/signals.json`)：SignalStore 持久化，重启恢复

## 七、盘前简报系统

每个交易日 9:25 自动执行（macOS crontab + `pre_market_cron.sh`），生成报告推送到微信：

```
══ 盘前简报 07/13 09:25 ══

【外盘】纳斯指-0.8%  标普指0.0%  道指指+1.1%
恒指 +0.3%  → 外盘偏暖
```

## 十三、技术亮点

1. **AI Agent 观澜**：7 种问题类型自适应 + SSE 流式 + 6 条质量自检，LLM 输出前逐项验证
2. **智能偏离评分**：资金-价格二元印证矩阵替代线性归一化，区分「补涨」与「诱多」
3. **A/B 双轨互补**：追涨 + 低吸并行，情绪面轮动速度动态调节池大小
4. **三系统协作**：技术 + 情绪 + 消息，失联自动重分配权重
5. **三级风控熔断**：大盘/板块/个股分级防御，极端行情 A 池自动归零
6. **多级数据降级**：push2 退避重试 → 熔断器 → 腾讯 qt.gtimg.cn → DB 缓存
7. **K线事件自动标注**：底部区域/放量启动/天量/洗盘/反包/加速，AI 引用具体日期
8. **诊断数据捷径**：前端预加载 diagData → 后端免重复 API，节省 3 次调用
9. **结构化诊断卡片**：四宫格 + 评分条 + 信号标签 + 操作建议芯片，一眼看清
10. **盘前预判闭环**：隔夜外盘 → 竞价异动 → 板块方向 → 策略建议，9:25 自动推送
11. **Multi-Agent 辩论**：三位独立分析师 + 主席综合判断，不同视角交叉验证
12. **持仓陪跑**：实时盈亏分析 + AI 操作策略，入场/目标/止损明确给出
