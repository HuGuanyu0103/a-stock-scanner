# A 股短线选股系统 — 完整技术文档

> 适用周期：超短线（2-4 天持股）  
> 当前版本：v4.0  
> 文档生成日期：2026-07-06  
> 代码总量：~9800 行（29 个文件）

---

## 一、产品定位

面向 A 股个人投资者的**实时盘中选股工具**。核心思路是「**板块定方向 → 资金选个股 → 多系统交叉验证**」。不做自动交易，专注选股信号发现。

**核心能力**：
- 盘中实时监控板块资金流向（概念 + 行业），每 3 秒刷新
- 从热板块成分股中多因子评分选出候选池（A 追涨 + B 低吸各 25 只）
- 技术面、情绪面、消息面三系统独立运行、交叉验证
- 盘前简报自动推送微信（外盘映射 + 竞价异动 + 今日策略）

```
Layer 1 — 数据层 (layer1_data/)

Layer 3 — 回测层 (layer3_backtest/)
  └─ backtest.py          策略回测（持股周期/止盈止损/评分过滤）

Layer 4 — 分析层 (layer4_analysis/)
  └─ analyzer.py          个股分析 + 市场简报 + 报告生成
```

## 三、核心策略详解

### 3.1 A/B 双轨选股

系统同时维护两条独立管道，互补覆盖：

**A 池 — 当日热力追涨**
```
热板块排名（概念 Top5 + 行业 Top5，双维度：资金流 + 价格动量）
  → 合并去重 (10-15 个板块)
  → 成分股下钻（每板块取主力净流入 Top 50）
  → 去重 + 过滤 + 9 因子评分
  → 板块集中度管控（每板块 ≤8 只）
  → Top 25 输出
```

**B 池 — 周期回调低吸**
```
SectorReviewer 回溯近 3 日
  → 筛选：累计流入≥3亿 + 累计涨幅达标(按规模分级) + 曾入 Top 50 + 当日回调
  → 成分股下钻 (Top 50)
  → B 池专属评分（取消低开惩罚、独立偏离逻辑）
  → Top 25 输出
```

**动态池分配**：由情绪面轮动速度决定 A/B 比例

| 轮动速度 | A 池 | B 池 | 策略倾向 |
|:--------:|:----:|:----:|----------|
| < 0.3（慢） | 35 | 15 | 追涨为主 |
| 0.3–0.6（中） | 25 | 25 | 攻守平衡 |
| 0.6–0.85（快） | 15 | 35 | 多低吸 |
| > 0.85（极快） | 5 | 45 | 只防守 |

### 3.2 两层评分体系

| 层级 | 来源 | 计算时机 | 权重 | 含义 |
|------|------|:------:|:----:|------|
| 盘中评分 | stock_selector | 每 60 秒 | 75% | 资金流 + 量价因子，「今天谁在涨」 |
| 日评分 | daily_scorer | 盘前一次性 | 25% | 技术面 + 情绪信号，「谁形态好」 |

融合方式：日评分在全量样本中做百分位归一化后按 25% 权重并入。

### 3.3 盘中 9 因子评分模型

| 因子 | 权重 | 归一化 | 说明 |
|------|:----:|--------|------|
| volume_ratio 量比 | 20% | Min-Max | 超短线量是王 |
| price_deviation 智能偏离 | 16% | 资金-价格矩阵 | 核心创新，见 3.4 |
| net_main_ratio 主力净占比 | 16% | Min-Max + 置信度降权 | 资金确认信号 |
| intraday_position 日内位 | 12% | Min-Max + 惩罚 | 高位/低位惩罚 |
| open_return 开盘涨幅 | 10% | Min-Max + 方向惩罚 | 低开惩罚 |
| turnover_rate 换手率 | 8% | Min-Max | 流动性 |
| amp_ratio 振幅 | 6% | Min-Max | 盈利空间 |
| short_momentum 短动量 | 6% | Min-Max | 近 5 日趋势 |
| breakout_dist 突破距离 | 4% | Min-Max | 距 20 日高点 |

### 3.4 智能偏离评分（核心创新）

替代传统线性归一化，用**资金-价格二元印证**打分：

```
                    跑输板块              跑赢板块
                  (deviation<0)         (deviation>0)
  ┌─────────────┬─────────────────┬─────────────────┐
  │ 主力强流入   │  补涨潜力  1.0  │  强势龙头  1.0  │
  │ net_ratio>5 │  (资金抄底)     │  (资金追涨)     │
  ├─────────────┼─────────────────┼─────────────────┤
  │ 主力温和流入 │   滞涨   0.40   │  温和偏强 0.75  │
  │ net_ratio>0 │  (等待催化剂)   │                 │
  ├─────────────┼─────────────────┼─────────────────┤
  │ 主力持平     │    0.25        │  一般    0.55   │
  ├─────────────┼─────────────────┼─────────────────┤
  │ 主力流出     │  真弱势   0.0   │ 拉高出货  0.1   │
  │ net_ratio<0 │  (资金抛弃)     │  (诱多嫌疑)     │
  └─────────────┴─────────────────┴─────────────────┘
```

### 3.5 信号推断体系（13 种）

**A 池信号（10 种）**：放量上攻、放量突破、补涨潜力、资金驱动、量价齐升、弱势回避、滞涨关注、温和吸筹、高位风险、盘中观察

**B 池专属（3 种）**：主线分歧低吸、板块洗盘承接、缩量止跌企稳

每种信号均附带持股天数 + 固定止盈止损 + ATR 动态止盈止损建议。

### 3.6 三级系统性风控熔断

| 级别 | 触发条件 | 动作 |
|:----:|------|------|
| **大盘** | 上涨板块占比 < 8% | A 池归零，全部转 B 池防守 |
| **板块** | 主力净流出 > 20 亿 + 跌幅 > 3% | 该板块成分股得分 ×0.5 |
| **个股** | 开盘后跌幅 > 4% + 现跌幅 > 5% | 直接剔除候选池 |

### 3.7 过滤规则链

```
全量成分股 (15板块 × 50只/板块 ≈ 750)
  → 智能去重（跨板块时保留资金流入最强的归属）
  → 板块排除（688科创板、8/9北交所）
  → 流动性过滤（流通市值≥30亿 A / ≥20亿 B、换手≥0.5%）
  → 涨停板过滤（反推涨停价，已涨停剔除）
  → 急跌熔断过滤（开盘后持续下挫剔除）
  → 诱多出货预警（高位+流出+高开低走剔除）
  → 极端背离剔除（价格大涨+主力明显流出）
  → 板块集中度管控（每板块≤8只）
  → Top 25 + 25 输出
```

## 四、数据基础设施

### 4.1 数据源

| 数据 | 接口 | 频率 | 说明 |
|------|------|:--:|------|
| 概念板块资金流 | push2 `m:90+t:3` | 3 秒 | 全量分页拉取 + 反向兜底 |
| 行业板块资金流 | push2 `m:90+t:2` | 3 秒 | 同上 |
| 北向资金 | push2 `/api/qt/kamt/get` | 6 秒 | 沪深港通净流入 |
| 板块成分股 | push2 `b:板块代码` | 60 秒 | 含日内高低开 + 资金流 |
| 全 A 股资金流排名 | push2 `m:0+t:6,...` | 按需 | 兜底日评分用 |
| 交易日历 | akshare `tool_trade_date_hist_sina()` | 启动时 | 判断节假日休市 |
| 涨停板数据 | akshare `stock_zt_pool_em()` | 5 分钟 | 情绪面用 |
| 新闻标题 | 财联社 cls.cn | 60 秒 | 消息面用 |
| DeepSeek LLM | deepseek-chat / deepseek-reasoner | 10 分钟/事件驱动 | 消息深度分析 |

### 4.2 板块白名单体系

25 个自选板块，通过三种方式映射到东方财富 API：

- **精确匹配**（13 个）：「光通信模块」「数据中心」「军工」等
- **名称映射**（9 个）：「人形机器人」→「机器人执行器」、「AI 芯片」→「华为昇腾」等
- **加权合成**（11 个）：「半导体」= 模拟芯片设计×0.6 + 华为昇腾×0.4 等

### 4.3 持久化

- **SQLite** (`collector.db`)：板块快照分钟级时间序列，供回放和回溯
- **JSON 缓存** (`data/daily_scores_YYYYMMDD.json`)：日评分全市场扫描结果
- **JSON 缓存** (`data/last_picks_result.json`)：最后一份真实选股结果，灾备
- **JSON 信号** (`data/signals.json`)：SignalStore 持久化，重启恢复

### 4.4 降级策略

```
API 失败 → 持久化缓存 → 兜底评分(资金流排名) → 空池告警
子系统宕机 → 权重自动按比例重分配给存活系统
```

## 十二、技术亮点

1. **智能偏离评分**：资金-价格二元印证矩阵替代线性归一化，区分「补涨」与「诱多」
2. **A/B 双轨互补**：追涨 + 低吸并行，情绪面轮动速度动态调节池大小
3. **三系统协作**：技术(70%) + 情绪(20%) + 消息(10%)，失联自动重分配
4. **三级风控熔断**：大盘/板块/个股分级防御，极端行情 A 池自动归零
5. **资金流置信度**：承认主力净流入是统计估算，价格-资金背离时自动降权
6. **全量数据采集**：分页拉取 + 反向兜底，确保覆盖净流出板块
7. **白名单加权合成**：缺失板块用关联板块加权平均，覆盖 25 个自选板块
8. **多级降级策略**：API 失败 → 持久化缓存 → 兜底评分 → 空池告警
9. **盘前预判闭环**：隔夜外盘 → 竞价异动 → 板块方向 → 策略建议，9:25 自动推送
10. **日评分融合**：盘前技术面 + 盘中资金面，百分位归一化 25% 权重融合
