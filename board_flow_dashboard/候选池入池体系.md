## 二、两层评分体系

候选池的每只股票由**盘中评分**和**日评分**两层构成，两者独立计算后展示：

| 层级 | 来源 | 计算时机 | 含义 |
|------|------|----------|------|
| **盘中评分** (score) | `stock_selector.py` | 每 60 秒盘中实时 | 资金流向 + 量价因子，反映"今天谁在涨、谁在买" |
| **日评分** (daily_combined_score) | `daily_scorer.py` | 盘前一次性 | 技术面 + 情绪信号，反映"谁形态好、谁有催化剂" |

前端同时展示两个分数，但不做加权合并——保留两个独立维度的判断。

## 三、盘中评分（score）详细算法

### 3.1 数据流

```
Step 1: 获取热板块
  ├─ 优先从 collector 内存读取（概念 Top 5 + 行业 Top 5）
  └─ 失败时降级为直接调 push2 API

Step 2: 板块去重
  └─ 同名板块只保留一次

Step 3: 下钻成分股
  └─ 每板块取主力净流入 Top 10 个股
  └─ API 字段: f12(代码) f14(名称) f2(现价) f3(涨跌幅) f8(换手率)
               f15(最高) f16(最低) f17(今开) f37(量比)
               f62(主力净额) f66(振幅) f184(主力净占比)

Step 4: 计算衍生因子
  ├─ price_deviation = 个股涨跌幅 - 板块涨跌幅
  ├─ intraday_position = (现价 - 最低) / (最高 - 最低)
  └─ open_return = (现价 - 今开) / 今开 × 100

Step 5: 智能去重
  └─ 同股票出现在多个板块时，保留 net_main_inflow 最强的归属

Step 6: 7 因子评分 → 排序 → 候选池 Top 25
```

### 3.2 七因子权重

| 因子 | 权重 | 归一化方式 | 方向 | 说明 |
|------|:----:|------------|------|------|
| **net_main_ratio** | 28% | Min-Max 标准化 | ↑ 越大越好 | 主力净流入占成交额比例，核心资金指标 |
| **price_deviation** | 20% | **智能条件判断** | ↓ 条件决定 | 个股相对板块的偏离度，需资金印证 |
| **volume_ratio** | 15% | Min-Max 标准化 | ↑ 越大越好 | 当日成交量 / 近5日均量，放量才活跃 |
| **intraday_position** | 12% | Min-Max + 惩罚项 | 中间偏上最优 | 日内相对位置，(现价-低)/(高-低) |
| **open_return** | 11% | Min-Max + 方向惩罚 | ↑ 越大越好 | 开盘后涨幅，负值打 3 折 |
| **turnover_rate** | 8% | Min-Max 标准化 | ↑ 越大越好 | 换手率，活跃度指标 |
| **amp_ratio** | 6% | Min-Max 标准化 | ↑ 越大越好 | 振幅，波动空间 |

### 3.3 智能偏离评分（_smart_deviation_score）

替代简单的 Min-Max 归一化，用**资金-价格印证逻辑**：

```
                    跑输板块          跑赢板块
                  (deviation<0)     (deviation>0)
  ┌─────────────┬─────────────────┬─────────────────┐
  │ 主力强流入   │   补涨潜力 1.0   │  强势龙头  1.0  │
  │ net_ratio>5 │  (资金抄底)      │  (资金追涨)     │
  │    or >10   │                 │                 │
  ├─────────────┼─────────────────┼─────────────────┤
  │ 主力温和流入 │    滞涨 0.40     │   温和偏强 0.75 │
  │ net_ratio>0 │  (等待催化剂)    │                 │
  │    or >3    │                 │                 │
  ├─────────────┼─────────────────┼─────────────────┤
  │ 主力持平     │      0.25       │    一般 0.55    │
  │ net_ratio≈0 │                 │                 │
  ├─────────────┼─────────────────┼─────────────────┤
  │ 主力流出     │   真弱势 0.0     │  拉高出货 0.1   │
  │ net_ratio<0 │  (资金抛弃)      │  (诱多嫌疑)     │
  └─────────────┴─────────────────┴─────────────────┘
```

核心逻辑：**价格方向必须有资金流印证**，不能一刀切奖励"跑输板块"。

### 3.4 日内位置惩罚

| 位置范围 | 惩罚 | 含义 |
|----------|:----:|------|
| `intraday_position > 0.85` | ×0.4 | 高位追涨风险，已接近日内高点 |
| `intraday_position < 0.3` | ×0.6 | 低位弱势，可能继续下探 |
| `0.3 ≤ position ≤ 0.85` | ×1.0 | 正常区间，不调整 |

### 3.5 开盘涨幅方向惩罚

| 条件 | 惩罚 | 含义 |
|------|:----:|------|
| `open_return ≥ 0` | ×1.0 | 开盘后上涨，不惩罚 |
| `open_return < 0` | ×0.3 | 开盘后下跌，大幅削弱该项得分 |

## 四、盘中信号推断（_infer_signal）

按优先级从高到低匹配，命中即返回：

| 优先级 | 信号 | 触发条件 |
|:------:|------|----------|
| 1 | 🟥 **放量上攻** | 净占比>15% + 量比>1.5 + 涨>3% + 日内位>0.6 |
| 2 | 🟧 **放量突破** | 量比>2 + 涨>2% + 开盘涨幅>1% |
| 3 | 🟧 **补涨潜力** | 净占比>10% + 跑输板块>1% + 日内低位<0.5 |
| 4 | 🟧 **资金驱动** | 净占比>8% + 日内高位>0.7 |
| 5 | 🟨 **量价齐升** | 量比>1.5 + 净占比>5% |
| 6 | ⚫ **弱势回避** | 跑输板块>2% + 主力净流出 |
| 7 | 🔵 **滞涨关注** | 跑输板块>2% + 主力未出逃 |
| 8 | 🔵 **温和吸筹** | 净占比>3% |
| 9 | ⚫ **高位风险** | 日内位>0.85 + 主力净流出 |
| - | ⚪ **盘中观察** | 以上均不满足（兜底） |

## 五、日评分（daily_combined_score）

### 5.1 正常模式：盘前全市场扫描

**入口**：`python3 daily_scorer.py --top 300`（每个交易日 9:25 自动/手动执行）

```
daily_scorer.py
  → layer1_data.DataFetcher   # 全市场行情
  → layer2_scan.StockScreener # 多因子扫描
    ├─ 技术面信号（均线、MACD、KDJ、RSI 等）
    ├─ 情绪面信号（涨停回踩、弱转强、连板梯队等）
    └─ 量化因子（动量、量比、大单比等）
  → JSON 缓存: data/daily_scores_YYYYMMDD.json
```

### 5.2 降级模式：自动兜底

当日评分缓存不存在时（如没跑 `daily_scorer.py`），自动调用 `fetch_stock_fund_flow_rank()` 获取全市场主力资金流 Top 100，生成简易兜底评分：

```python
combined_score = 排名分×0.3 + 净额分×0.4 + 占比分×0.3
# 排名分: Top 1=10, Top 100≈0
# 净额分: max(0, min(10, net_main×1.5 + 5))
# 占比分: max(0, min(10, ratio + 5))
```

日志示意：
```
日评分缓存缺失，自动生成兜底评分...
兜底日评分生成: 100 只股票
```

## 六、候选池过滤规则

### 当前规则

| 规则 | 说明 |
|------|------|
| 排除科创板 `688xxx` | 50 万门槛，散户参与度低，流动性差 |
| 保留创业板 `300xxx` | 散户可交易，20cm 弹性 |
| 每板块取 Top 10 成分股 | 按主力净流入排序 |
| 热板块取 Top 5（概念+行业各5） | 共 10 个热板块 |
| 候选池输出 Top 25 | 最终展示数量 |
| 60 秒缓存 | 避免同分钟内重复调用 API |

### 股票出现跨板块的处理

同一只股票可能同时属于多个板块（如"AI芯片"+"半导体"+"数据中心"），去重时：
- 比较各板块归属下的 `net_main_inflow`
- **保留主力资金流入最强的那个板块归属**
